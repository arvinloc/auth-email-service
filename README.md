# Сервис авторизации с подтверждением почты для авторизации в системе. Тестовое задание от InnoTech Solutions

Сервис аутентификации с SMTP magic links, JWT токенами и интеграцией с ML микросервисом для определения тональности текста.


## Для запуска необходимо:
```bash
git pull
```
```bash
cp .env.example .env
```
```bash
docker compose up --build
```

Для очистки содержимого использовать:
```bash
docker compose down -v 
```
